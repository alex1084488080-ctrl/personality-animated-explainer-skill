# 人格动画介绍视频 Skill

用于制作约 60 秒的 MBTI／人格主题横版动画介绍视频。

它会保留已有动画的主体叙事，在画面空位加入与人格匹配的低多边形角色，并根据音乐卡点安排字幕、局部特效和高潮段的视觉加强。

## 使用方式

将本仓库中的 `SKILL.md` 加入支持 Claude Skills 格式的 Agent 环境，或把它作为工作流说明提供给视频制作 Agent。

## 流程特点

- 原动画保持可见，辅助角色不覆盖主体画面。
- 角色服装、道具、色彩与人格特征匹配。
- 按音乐节奏安排角色、字幕和局部粒子／光环。
- 交付前检查中文文案、时长、画幅、音轨和关键帧。
